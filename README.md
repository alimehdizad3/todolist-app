##  Features

- User Registration
- User Login & Logout
- Profile Management
  - Change Username
  - Change Email
  - Change Password
- Create Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Completed
- Search Tasks
- Filter Tasks (All / Completed / Pending)
- Optional Deadline for Tasks
- Success & Error Messages
- Authentication Required
